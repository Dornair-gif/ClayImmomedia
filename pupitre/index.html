Pupitre ClayImmo

Un sujet se valide une seule fois : la validation couvre toutes ses déclinaisons (reel, carrousel, LinkedIn, fiche Google, YouTube). Ouvrez les déclinaisons pour relire les textes et les visuels, puis validez le sujet ou demandez une correction en quelques mots. Les sujets validés sont programmés automatiquement chaque matin ; rien ne part sans validation.

Vous voyez le pupitre en lecture seule. Pour valider, demandez à Maneli un accès qui permet d’utiliser la page.
